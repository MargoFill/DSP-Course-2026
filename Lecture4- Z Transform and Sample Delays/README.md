# Z Transform and Sample Delays
## Tasks
### 1. Identify the sample represented by each term in X(z).
- The term $1$ represents the sample at $n=0$, where $x[0] = 1$.
- The term $2z^{-1}$ represents the sample at $n=1$, where $x[1] = 2$.
- The term $z^{-2}$ represents the sample at $n=2$, where $x[2] = 1$.
### 2. Write the Z-transform of the delayed signal.
` X(z) = z⁻¹ + 2z⁻²+ z⁻³`
### 3. Explain why delaying the signal by one sample multiplies X(z) by z⁻¹.
In the Z-transform, the power of z represents the time step (with a negative sign). When a signal is delayed by 1 sample, every value is shifted to the right, meaning its time step increases by 1. This adds an extra -1 to the power of z for every term. Mathematically, factoring out this extra $z^{-1}$ from every term is exactly the same as multiplying the entire original $X(z)$ equation by $z^{-1}$.

### 4. Calculate y[0], y[1], y[2] and y[3] by hand. Compare them with MATLAB.
- $y[0] = 0.5(1) + 0.5(0) = 0.5$
- $y[1] = 0.5(2) + 0.5(1) = 1.0 + 0.5 = 1.5$
- $y[2] = 0.5(1) + 0.5(2) = 0.5 + 1.0 = 1.5$
- $y[3] = 0.5(0) + 0.5(1) = 0.0 + 0.5 = 0.5$

These manual calculations result in the sequence [0.5, 1.5, 1.5, 0.5], which matches the array output generated by MATLAB.

### 5. Explain how b = [0.5 0.5] represents the two terms in H(z).

In MATLAB's filter(b, a, x) function, the vector b defines the numerator coefficients of the transfer function in ascending powers of $z^{-1}$. The first element b(1) = 0.5 corresponds to the $z^0$ coefficient (the multiplier for the current input $x[n]$), and the second element b(2) = 0.5 corresponds to the $z^{-1}$ coefficient (the multiplier for the previous input $x[n-1]$).

### 6. Change the system to H(z) = 0.8 + 0.2z⁻¹. Update b, run the code again, and explain which input sample now has more influence on the output.

In this modified system, the current input sample $x[n]$ has much more influence on the final output because its multiplying weight is 0.8, whereas the previous input sample $x[n-1]$ only contributes a weight of 0.2 to the sum.
